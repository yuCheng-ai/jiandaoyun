# 通用业务设计平台

保留 Vue 3 + TypeScript 中文工作台，并以 NestJS + PostgreSQL 推进真实协作。当前完成工程迁移和 M1 基础链路，阶段目标见 [开发计划](docs/development-plan.md)，实际证据见 [M1 验收](docs/backend-m1-qa.md)。

## 预览

本地开发服务：<http://127.0.0.1:5198/#/>。

- 首页：`/#/`
- 团队协作（已连接本地后端）：`/#/collaboration`
- OA 表单列表：`/#/apps/oa`
- 表单设计器：`/#/apps/oa/forms/untitled/design`
- 流程设计器：`/#/apps/oa/forms/untitled/flow`
- 扩展配置：`/#/apps/oa/forms/untitled/extensions`
- 通讯录与内部员工：`/#/admin/organization`
- 角色与角色组：`/#/admin/roles`
- 权限查询：`/#/admin/permissions`
- 支付管理：`/#/admin/payments`

重新启动时：

```bash
npm install
npm run setup:local
npm run db:up
npm run dev
```

工程目录：

```text
frontend/           Vue 页面、领域层、Repository、Pinia、前端测试与资源
backend/            NestJS 服务、PostgreSQL 迁移、真实数据库集成测试
packages/contracts/ 共享表单 Schema 与 API 类型
scripts/            联合开发启动、本地配置、Sites 构建
```

Node.js 22 与 Docker Compose 用于本地开发。`setup:local` 生成被忽略的 `.env`，不会覆盖已有配置。`admin`、`editor`、`reviewer` 的随机密码分别保存在 `PLATFORM_ADMIN_PASSWORD`、`PLATFORM_EDITOR_PASSWORD`、`PLATFORM_REVIEWER_PASSWORD`；开发账号与原工作台的本地成员切换不同。不要把 `.env` 提交到版本库。独立数据库使用 55432 端口，API 使用 3001，前端使用 5198。

团队协作支持发布不可变定义、记录新增与查询、子表列授权、字段级并发检测与真实持久化。当前服务端字段为文本、长文本、数字和单层子表；未支持规则会明确拒绝。任务模型已通过跨表依赖与等待的 API 测试，尚未接入原流程设计器。详见 [服务端契约](docs/backend-contracts.md)。

## 已实现的前端

- 工作台：首页引导、最近使用、应用搜索与创建、待办/发起记录入口、本地统计。
- 表单列表：分组、搜索、类型筛选、排序、列表/卡片、新建、重命名、复制、分组移动、回收站恢复。
- 表单编辑器：30 类字段、拖入和排序、属性面板、多选、复制、删除恢复、撤销重做、字段宽度、表单布局、子表单、多标签页、富文本和签名。
- 表单规则：必填、唯一值、格式、范围、条件显隐、隐藏值清理、算术公式、默认值、填写缓存及草稿。
- 选择字段：批量添加与去重、选项排序、多选默认值、其他表单记录作为动态数据源、显示字段/存储值配置、条件过滤和级联清理。
- 表间关联：记录搜索与单选/多选、条件筛选、多字段回填、关联明细表、记录详情、客户反查订单等反向关联。子表单行内映射保持独立作用域。
- 组织管理：部门层级与负责人、员工多部门/主部门、在职/停用/离职、搜索分页、批量调整、部门和角色归档恢复。
- 角色与权限：角色组、直接成员/部门动态成员、应用和表单操作授权、数据范围配置、成员权限合并查询。
- 共用选择器：部门树、成员搜索、角色筛选、单多选与移除、范围限制、当前用户/主部门/部门负责人默认值；表单与流程负责人共享组织数据。
- 运行态：桌面/手机预览、版本发布、填写提交、草稿继续填写、数据详情和 CSV 导出入口。
- 数据管理：展示列与顺序、按显示名称搜索、条件筛选、数值排序、分页、编辑记录、批量选择、回收站和恢复；编辑/删除/恢复联动本地推送事件，失败时整体回滚。
- 流程编辑器：审批、抄送、二路条件、子流程、插件节点；自由拖拽与连接、图校验、平移缩放、自动排列、快捷键、复制粘贴和撤销重做。
- 节点配置：负责人、字段可见/可编辑/简报、操作按钮、流转规则、时限；流程属性、JSON 导入导出、预览与本地模拟。
- 数据推送：事件与条件、目标地址、就地生成/显隐/复制/重新生成 Secret、本地签名验签、字段范围、实时 JSON、模拟测试、失败定位/重试、启停和归档恢复。
- 智能助手：事件条件、顺序动作、跨表新增/批量更新/更新或新增、固定目标版本、字段差异试运行、实际本地写入、整组回滚、失败定位与日志。
- 在线支付：演示商户、金额与说明绑定、支付条件和时机、独立订单、模拟收银台、失败重试、取消与过期、部分/全额退款、订单查询、结果字段回填、支付事件联动与刷新恢复。
- 提交提示：自定义成功文案、表单下方提示/结果页、继续填写开关；预览与正式填写共用结果组件，保存后随新版本生效。
- 流程插件：动作目录、常量/字段/模板输入、类型匹配回填、试运行、执行快照；本地金额计算和文本组合可以参与正式记录流转。
- 打印模板：字段选择与排序、A4/A5、横纵向、字号、抬头与页尾、子表明细、归档恢复；记录按其发布版本预览、直接下载中文 PDF 或请求系统打印。
- 数据详情：指定字段和顺序、单/双列、隐藏空值、记录信息与流程动态配置。
- 数据协作：固定文字与字段组合标题、实时预览、历史版本隔离；表格单元格修改复用字段控件与校验，展示联动差异，保留修改历史，支持未保存离开保护。
- 集成：字段通过稳定 ID 与流程权限关联，发布版本和编辑草稿隔离，数据详情按提交版本渲染。

首次进入包含示例应用和表单。通过“新建表单”创建普通表单，添加字段后可直接发布与填写。流程表单发布前需为审批节点选择负责人，或设置为发起人本人。

在表单列表点击“关联示例”，会新增“客户档案”和“销售订单”两张表及三条示例客户，不覆盖已有数据。可以选择区域筛选客户、自动回填联系人与电话，提交订单后从客户详情反查订单。管理后台新增成员后，表单与流程中的人员选择器立即使用同一份组织数据。

- 头像菜单：个人信息、切换体验成员、企业管理、返回工作台和产品说明；首页、列表及设计器复用。数据恢复按保存异常或编辑恢复场景提供入口，不作为日常账号操作。
- 本地保存保护：拒绝覆盖其他页面更新的快照；最近访问独立缓存；失败副本导出与设计另存为未发布表单。同源页面通过共享 Web Lock 保护业务变更、快照比较、写入与回滚，不支持安全锁时保留输入并拒绝写入。

## 范围说明

原前端交付范围与尚未完成的业务验收见 [docs/frontend-closure.md](docs/frontend-closure.md)。最新用户授权调整为前后端共同推进；既有前端义务继续保留。

正式填写草稿保存后有独立地址，连续保存/刷新/提交使用同一记录及原发布版本；已提交或其他成员的草稿不能隐式变成新记录。自动暂存通过确认恢复，设计预览不写入正式填写缓存。详见 [填写草稿验收](docs/filling-drafts-qa.md)。

除团队协作入口外，原工作台仍为前端实现与本地演示，数据保存在当前浏览器。发布链接仅在保存了该数据的浏览器中有效。初始成员和部门使用通用示例数据，可通过管理后台创建、编辑和保存；未连接真实企业通讯录或账号系统。角色授权提供配置与权限查询，不能替代服务端权限检查。

原工作台的完整审批执行、会签、消息通知、AI、OCR、地图自动定位、外部插件和持久附件存储尚未接入；相关字段或节点提供配置/填写界面。图片与附件在本地记录文件元数据，小图片保留预览。流程测试和数据中的审批动作演示节点路径，不执行外部服务。

默认条件表达式为 `申请金额 > 5000`，支持 `>`、`<`、`>=`、`<=`、`==`，可在属性中选择用于比较的表单字段。分支按连线顺序区分满足条件与其他情况。

未保存的编辑草稿保留于当前页面会话；点击保存后持久化。字段回收站仅当前编辑会话有效。自动填写缓存使用 sessionStorage；正式提交记录使用 localStorage。完整工作台同步尚未接通；新增协作入口通过独立 API Repository 持久化。

文件下载入口受浏览器宿主支持影响，内嵌浏览器未确认下载完成事件；设计 JSON 保留文本编辑/复制与导入路径。画布节点复制粘贴已实际验证。空格配合持续鼠标拖动、修饰键加滚轮仍需实体键鼠验收。

```bash
npm run build
```

最新结果（2026-10-08）：生产构建通过；312 项前端业务测试、12 项 PostgreSQL 集成测试、4 项静态资源/路由测试通过。后端测试需本地数据库已启动，并使用独立测试 schema。以下原型验收历史继续保留；本轮真实协作验收见 backend-m1-qa.md。浏览器验证覆盖新建、编辑、拖拽、复制、撤销、回收站、条件显隐、子表单校验、发布、填写与数据回显，以及组织管理、角色配置、范围选人、动态选项、关联回填、反向查询、发布版本隔离、推送失败重试及插件实际回填；390px 窄屏设计器、人员选择器、数据协作、快捷编辑、成员发布、模拟收银台、快捷填报和就地编辑恢复检查通过。通用弹窗关闭、取消、Esc、嵌套焦点及表单预览的验收见 [dialog-close-qa.md](docs/dialog-close-qa.md)。

完整证据见 [design-qa.md](design-qa.md)，工作台、表单设计器、列表和流程截图在 `docs/`。首页引导插画来自用户授权参考的产品页面；通用图标使用 Ionicons。此项目是实现参考，不是官方简道云产品。

数据推送与插件的逐项验收见 [docs/extensions-qa.md](docs/extensions-qa.md)。连接测试会在浏览器实际计算并核对签名，Secret 明确标为本地演示；HTTP 与通知仍为模拟，不连接外部服务器。配置保存后须发布新版本才影响新记录。新增、编辑、移入回收站和恢复记录均会触发对应的本地事件日志。PDF 已完成实际 5 页中文文件下载、文本完整性与逐页渲染检查，见 [PDF 文件交付验收](docs/pdf-delivery-qa.md)。系统打印机输出尚未确认；成员导出权限组合继续验收。

AI 快捷填报已支持字段、别名、说明、示例和图片目标配置，以及逐项检查、手动更正、覆盖/联动确认后回填到未提交表单。发布填写页和成员新增记录共用同一组件，候选范围遵守人员、部门与关联数据权限。当前为本地规则演示，只解析带字段名的文字或 JSON；图片仅附到指定字段，不执行自然语言推理或 OCR。完整证据见 [快捷填报验收](docs/quick-fill-qa.md)。

在线支付已完成配置、商户、模拟收银台和订单/退款管理，支付金额以每笔订单确认时的快照为准。所有操作仅保存本地演示数据，不连接支付渠道。支付成功、零元确认和退款可以回填结果字段并触发智能助手；成员付款、身份隔离、退款回填与 390px 配置已验收，详见 [支付验收](docs/payment-qa.md)。

推送提醒已支持事件/日期规则、成员/部门/角色或记录字段取人、字段消息模板、试运行、失败定位与执行记录。日期检查由页面按钮发起，成功标记独立于日志保存，刷新后不重复；所有消息通道仅模拟。验证记录见 [提醒验收](docs/reminders-qa.md)。

自定义按钮支持填写页、记录详情和列表行，提供显隐条件、字段更新、带值打开另一张表单、带参数打开链接及执行确认。记录更新沿用历史版本校验并触发本地数据事件；检查预览不产生业务操作。见 [自定义按钮验收](docs/buttons-qa.md)。

数据协作已实现数据标题与表格快捷编辑，在列表、详情和工作台使用同一标题逻辑；仅编辑原版本允许修改的字段，不重新发起流程。见 [数据协作验收](docs/collaboration-qa.md)。

成员发布支持权限组、组织范围、本人/部门/条件数据范围与字段权限；成员入口实际限制新增、编辑、删除、导出与打印。填写链接与收集时间/数量开关立即生效，不改写历史表单版本。支持本地切换成员体验，未接入认证。验收见 [成员发布](docs/member-publish-qa.md)。


智能助手已完成本地动作闭环。提交合同创建项目台账、再筛选并更新预算的真实记录路径与 390px 编排/取消保护已验收；试运行和日志重试均不改变业务记录。详细能力边界与证据见 [智能助手验收](docs/automation-qa.md)。

个人信息、数据推送、插件、智能助手、提醒、按钮、打印模板、支付配置、演示商户和快捷填报配置已支持自动暂存和刷新后就地恢复；正式表单填写遵循“自动暂存填写内容”设置。只在发现上次未保存内容时提示，正常输入不显示恢复横幅；恢复后仍需保存或提交。恢复文件导入与完整副本工具保留于异常处理路径。权限两阶段设置、组织编辑及其余内嵌配置继续接入，当前不提供自动合并。见 [配置恢复验收](docs/configuration-recovery-qa.md) 与 [编辑暂存验收](docs/editor-drafts-qa.md)。

Sites 继续使用根目录静态构建输出 `dist/client`、`dist/server/index.js` 与 `dist/.openai/hosting.json`。Sites worker 仅承载前端，不包含此 NestJS 后端；仅部署静态资源不会接通协作 API。
