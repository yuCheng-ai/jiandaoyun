# 数据与页面分离阶段验收

日期：2026-10-08，数据与页面验收更新至 20:44，关系交互及最新全量检查补充于 21:14，见 relations-ui-qa.md。范围是 M2 的数据、页面和关系基础接口，以及应用管理、页面设计、兼容记录升级和明细增删恢复；尚未完成 M2 及 E0–E8 整体目标。

## 已验证的契约和行为

- DataModel 定义稳定的数据字段、明细结构与永久约束；FormPageSchema 独立定义控件、字段绑定、布局、页面必填和只读设置。数据字段没有页面宽度等布局属性。
- 原前端 registry 中全部字段类型可转换并还原配置，标签页中的字段保留所在数据范围，明细保留子字段身份；此转换能力不代表所有高级字段都已支持服务端执行。
- 已有服务端定义获得独立数据版本与默认页面版本。重复和并发升级不重建历史记录，历史页面名称、字段及记录版本保留。
- 两个页面可以读取和修改同一条记录；页面移除字段不删除模型字段。纯布局发布只增加页面版本。
- 页面新增字段作为 additions 保存在页面草稿中。发布将模型版本、页面版本、字段绑定和版本计数一并提交。模型基线过期时拒绝发布并保留草稿；在写模型后注入页面写入故障，验证整个事务回滚，故障移除后可重试。
- 页面级必填不自动成为数据对象的永久约束。允许业务记录先保存部分内容，在指定页面提交时再校验该页面要求；失败不会部分保存字段或审计事件。
- 页面只读、隐藏与当前成员字段权限叠加；被页面排除的值和修改版本不返回，越过页面的字段修改请求被拒绝。原记录接口仍按其自身的服务端授权执行，不将页面布局误当作唯一权限来源。
- 页面绑定明确的数据版本，拒绝不兼容的记录；已发布版本不可修改。旧页面可以使用仅兼容新增字段的更新记录，返回值仍受该页面与成员权限限制。发布的自定义页面仍使用某字段时，模型修改会报告引用影响。
- 采用更新数据模型保留页面布局、别名和未发布新增字段，不自动插入新控件；新增字段同名、身份冲突或仍绑定被移除字段时保留当前草稿并阻止采用。
- 历史记录升级须管理员明确选择并预览，仅支持兼容新增。记录版本检查、字段补全、保存和审计在同一事务中执行，审计故障完整回滚；重试具有幂等性。原值、行身份和既有字段修改版本保留。页面新增字段也检查历史身份，不能用已经删除的字段 ID 换一种类型重新创建。
- 明细新增和删除同时检查结构版本、字段权限及行内修改版本。删除前可在页面撤销，保存后可读取有权恢复的最近删除记录；恢复保留行 ID、校验当前结构和所有列权限、提升字段修改版本，避免旧提交覆盖恢复后的内容。旧删除快照、隐藏列、结构冲突和非法历史值不能绕过检查。
- 普通成员列表显示已发布页面的名称和数据版本，不显示尚未发布的改名。
- 关系 API 已覆盖配置发布、候选筛选、快照与实时读取、当前权限过滤、字段映射事务、关联基数竞争、明细引用阻断和重启恢复；配置与记录界面已接入，双账号和按行浏览器证据见 relations-ui-qa.md。

## 迁移与接口

003-data-pages.sql 增加独立数据版本、页面及页面版本；004-page-field-drafts.sql 增加页面待发布字段；005-applications.sql 增加应用归属并将旧定义归入默认应用。已应用的迁移保持原内容。数据转换在启动时持锁、事务执行，不修改旧的不可变定义版本。

- /api/data-objects 及其草稿、保存、发布接口管理数据对象。
- /api/pages 及其草稿、保存、发布接口管理独立页面。
- POST /api/pages/:id/publish-preview 校验 expectedRevision，返回字段/控件变化、相关配置、记录/任务版本和预览 token。新页面 UI 确认发布提交 impactToken；发布事务重新检查，不匹配返回 409。
- /api/applications 管理应用目录；对象和页面列表支持 applicationId 过滤。
- /api/pages/new-business 原子创建空数据对象与页面并支持幂等重试；/api/pages/:id/editor 返回编辑契约，/api/pages/:id/form 返回经授权过滤的填写配置。
- /api/pages/:id/records 通过明确 pageVersion 提交；/api/pages/:id/records/:recordId 用于按页面读取和修改记录。
- /api/data-objects/:id/published-model 提供页面采用字段所需的最新已发布模型。
- /api/pages/:id/records/:recordId/upgrade 的 GET 预览和 POST 执行绑定明确页面版本的兼容记录升级。
- /api/records/:id/removed-rows 及页面范围的对应入口返回当前有权恢复的已删除明细；恢复通过原记录 PATCH 的 rowChanges 命令提交，遵循页面、字段、版本和幂等校验。
- 原 /api/definitions 保留兼容入口。旧表单发布仍包含默认页面的同步，不把这个旧入口称为纯页面发布。
