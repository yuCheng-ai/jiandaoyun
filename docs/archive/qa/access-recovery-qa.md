# 发布设置与权限组编辑恢复验收

2026-10-09。本轮补齐原本地前端的两阶段编辑：权限组“应用到设置”只改变父编辑器，父页面“保存发布设置”成功后才改变有效权限。刷新恢复需要分别确认，不自动授予权限。

## 已实现

- 父发布设置、已有权限组和新建权限组各自保留编辑内容。恢复检查表单结构、原配置、当前成员；子编辑器还检查父设置上下文。来源变化不直接恢复，配置在打开期间变化也拒绝覆盖，并提供明确放弃后重新读取。
- 暂存适配器校验成员、权限枚举、字段绑定、筛选结构和组身份；保留未完成的空数量上限、空名称及筛选输入，业务校验在应用或保存时执行，不把不完整输入转换成更宽的权限或“不限”。
- 子编辑器等待父设置接收并完成恢复副本保存后，才清理自己的副本并关闭。父暂存失败时回到原父设置，保留子输入，可重试。取消子编辑不放弃父设置。
- 父保存失败、返回 false 或异常时保留输入和恢复副本；保存中显示状态并阻止重复写入、编辑和离开。只有成功回执才标记已保存和清理当前副本。
- 离开父页面须选择继续、明确放弃或保存后离开。保存失败仍在确认窗口内显示原因，重试成功才离开；明确放弃不会在卸载时重新产生副本。
- 复用 useEditorDraft、useDraftDismiss、EditorDraftNotice 和 BaseDialog，没有引入独立的弹框关闭机制。

## 浏览器证据

独立表单“权限恢复 · 两阶段验收”，ID form_1047cd4b3589，位于 OA审批系统，发布版本 V1。

1. 清空父设置数量上限，新建“跨部门复核 · 恢复验收”权限组，选择演示成员张三。两层都不保存，刷新页面。
2. 父设置显示恢复提示，确认后数量上限仍为空。再打开新建权限组，单独确认恢复，名称、张三及只读字段权限保留。
3. 应用权限组后，父页面仍为未保存；保存被空上限校验拦住。再次刷新并恢复父草稿，权限组仍存在，子编辑器不再提示已交接的旧副本。
4. 390×844 下检查子窗口，文档宽度 390、对话框宽度 358，无横向溢出，正文可滚动、取消及应用可达。关闭未修改子窗口，填上限 20，启用成员访问并保存。
5. 刷新后已保存、上限 20、权限组 1 位有效成员，无恢复提示。提交一条“两阶段恢复后的只读记录”，张三可查看详情，没有编辑、删除、导出或添加入口；切换王五显示没有可用权限，不显示记录。
6. 验证后恢复张三及默认窗口，浏览器 warning/error 为空。未在浏览器故意破坏存储；配额和保存异常由组件测试覆盖。
