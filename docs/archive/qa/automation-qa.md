# 智能助手 Pro 本地动作验收（2026-10-08）

本轮实现触发条件、顺序动作、跨表记录新增/更新/更新或新增、字段映射、纯试运行、实际本地写入与执行日志。沿用紧凑界面与稳定字段 ID，没有增加独立后端。官方产品参考：[设计入口与步骤](https://hc.jiandaoyun.com/doc/19049)。本地能力与边界以下面的实测为准，不声明与官方所有自动化能力完全一致。

## 已完成的业务路径

| 路径 | 结果 |
| --- | --- |
| 新建与配置 | “什么情况下触发 → 依次执行什么 → 试运行与保存”，提供四种数据事件、AND 条件、动作名称、目标版本、来源字段/固定值、无匹配策略和显式全表更新选项 |
| 动作顺序 | 后续动作读取前面产生的暂存记录；每个字段绑定始终读取同一份触发快照；上下移动、删除、添加可操作 |
| 跨表新增 | 按固定发布版本的默认值和字段类型生成数据，执行完整必填/唯一值/动态选项/人员范围检查；流程表单进入自身流程 |
| 批量更新与 upsert | 仅处理有效、非草稿记录；使用目标条件和来源值匹配。无匹配可跳过、停止，或选择更新/新增动作。已有记录保留自身版本 |
| 失败处理 | 同一助手内任一步失败，整组目标变更不写入；来源操作保留，失败记录可定位原配置。存储失败同时撤回来源、目标记录、历史与日志 |
| 试运行/重试 | 计算逐字段差异，仅保存日志；重试使用配置及触发值快照、读取当前目标数据，不创建或修改业务记录 |
| 版本与管理 | 配置进入不可变发布版本；目标版本固定；支持启停、复制、归档恢复；失效来源字段进入删除影响提示，目标归档或版本不兼容会失败 |
| 防重复触发 | 草稿不触发，值未变化的编辑/审批流转不触发助手；助手派生写入不递归发出扩展事件 |

## 浏览器证据

验收来源：`合同提醒 · 验收示例`（`form_fe15f7896d03`，V4）。目标：`项目申请示例`（`form_497d55e3fd28`，V1）。助手为“合同同步项目台账”，依次“建立项目台账”“核定预算金额”。

1. 名称映射来源合同名称，新增台账使用原默认预算 100。第二步按项目名称等于来源合同名称匹配，预算写入 800。
2. 试运行显示新增一条、匹配更新一条、最终影响一条；差异为预算 100 → 800。清空样本合同名称后，目标必填校验显示“请填写项目名称”，不写入记录；修正样本后恢复成功。
3. 保存并发布 V4，正式提交“合同同步 · 智能助手验收”。目标表中出现唯一的新记录 `entry_73cde62c52c0`，预算 800，历史记录两步助手动作。原项目记录仍保留，目标共两条。
4. 日志区可区分正式表单事件与试运行。失败日志重试保留失败输入，定位按钮打开对应助手。
5. 390×844 固定同源框架中可以排序、编辑金额、试运行；将 800 临时改成 900 后，只显示预计变更。取消时提示继续编辑/放弃修改；放弃后保持已保存配置。文档宽度与滚动宽度均为 390，弹窗宽度与滚动宽度均为 356，无横向溢出。

主验收页读取最近 20 条 warn/error 日志为空。

## 当前边界

- 本地同步事件模型，无服务端队列、跨标签页并发锁、后台定时任务或真实外部调用。目标流程中的外部插件仍使用模拟响应，日志明确说明。
- 最多 50 个助手/表单、20 个动作/助手、200 条更新/动作、500 次变更/整组；达到限制提示缩小范围，不截断后部分提交。
- 映射使用与自定义按钮一致的可写主表/标签页字段；未实现子表逐行展开建多条、子表行更新、复杂分支或延时调度。
- 目标表的填写收集开关用于成员/公开填写；助手作为设计者配置的内部数据动作执行完整数据校验。真实权限与安全边界仍需服务端实现。
- 整体持续目标还包括在线支付与 AI 快捷填报前端、打印深度/系统输出和下载落盘核实。
