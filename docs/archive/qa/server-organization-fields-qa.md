# 成员与部门字段服务端验收

更新时间：2026-10-09 04:03（北京时间）。本阶段补齐新数据对象、表单页面和记录运行中的组织字段，不代表原本地应用已经迁移或整个平台完成验收。

## 本阶段行为

成员单选、多选，部门单选、多选均可从新页面画布创建，也可在数据管理中配置。新字段与控件随页面一起发布；共享字段的组织规则在页面中只读，在数据管理中统一修改。主字段和单层明细列使用同一契约，保存真实服务端身份，不以名称或旧本地身份替代。

选择范围支持全部、指定部门／成员／角色的并集、当前成员所在部门，以及主表或同一明细中的部门字段。可配置包含下级部门。跨明细取值、自身依赖及依赖循环在发布时被拒绝。默认方式包括指定身份、当前成员、当前成员主部门和主部门负责人；单选与多选分别限制数量。默认值由登录身份和当前组织计算，再由字段选择范围过滤。组织维护增加部门负责人配置，保留已有组织标识；使用原组织 JSON 存储，不增加数据库迁移。

候选接口按数据版本、页面、记录与任务上下文检查权限，只返回该字段可选的身份名称和 ID。普通成员不能借此读取完整管理目录、查询隐藏或只读字段的候选，或通过请求参数修改不可编辑的部门条件。行任务不能查询其他行的可编辑候选。记录响应只补充可读字段中已选身份的名称和当前状态。

服务端在最终提交状态下检查字段及其部门依赖，覆盖新增、字段修改、明细新增／恢复、关系回填及任务保存。失败回滚整个操作。未改变的历史身份保留；停用成员、归档部门不能成为新的选择。改变部门条件时须重新满足新范围，客户端保留原输入供用户处理，不静默清空业务值。

数据模型发布检查按当前检查人、当前组织和记录部门条件统计组织字段不符合新规则的记录，界面明确检查身份。范围明细使用业务名称。历史记录仍按原发布版本读取。记录兼容升级展示实际计算的默认名称；组织默认值变化后，旧预览标识不能继续提交，须重新检查。明细恢复预览与真正恢复使用一致的校验。

设计预览复用服务端组织目录和当前登录身份，避免落回本地示例成员。正式页面的成员／部门控件、规则配置和负责人配置共享选择器；支持搜索、单选／多选、取消保留、失败重试和键盘焦点。过期候选响应不覆盖新部门范围，清空的值不会被异步默认值再次填回。关系候选、回填预览及关联展示使用身份名称，保留存储 ID。

## 浏览器验收

在“字段与页面验收”应用中新建“组织字段验收”，保留原对象和其他页面草稿。

1. 从页面增加办理部门、经办人、协办成员、协作部门，以及处理明细中的明细负责人。经办人由办理部门限制；办理部门和明细负责人分别采用当前主部门、当前成员默认值。
2. 保存草稿，预览显示服务端组织“其他业务组”和登录成员“平台管理员”。发布检查列出 6 项字段，确认后数据和页面均为 V1。
3. 正式填写时，主表和新明细默认值一致；成员候选为服务端的三个登录成员。多选保存录入成员与核对成员、两个协作部门。
4. 将办理部门由其他业务组改成协作业务部，保留原经办人并提交。后端明确拒绝范围外的经办人，其他输入与明细保留，没有产生记录。重新选择的候选只有录入成员、核对成员。
5. 390×844 下完成重新选择和提交；文档宽度与滚动宽度均为 390。保存后重新打开记录，所有选择、明细负责人与字段版本保留。尺寸已恢复。
6. 返回数据管理，看到同一数据对象中的部门、成员、多成员、多部门及明细字段，页面待发布字段为空；共有一个页面使用它。最后浏览器错误／警告为空。
