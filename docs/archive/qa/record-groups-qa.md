## 产品行为

- 应用数据管理的“数据权限 → 权限组管理”管理共享数据的授权。同一数据对象的不同页面复用组规则，再受各页面字段范围限制。
- 普通表单仍然可以直接拖入新字段。字段和页面绑定先保存在页面草稿，发布时一起提交；数据管理收录发布后的字段。新字段默认不向现有权限组授权，管理员按业务需要配置。移除页面控件仍不删除共享字段或历史数据。
- 权限组模式与原按成员、部门、角色叠加授权的模式独立。启用组模式后旧授权保留但不参与计算；切回原模式才恢复。管理员可读取全部数据，成员按实时组织资格执行。
- 一个适用组自动选中；多个组必须选择。只有配置允许时才展示“合并我适用的权限组”，不会默认合并。组被禁用、归档、撤销成员资格或不再允许合并时，旧选择失效。
- 每组分别定义记录范围、操作、主字段、子表列及关联权限。先确定组是否适用于该记录和操作，再限制父子字段，最后合并。查看组不能借给导出组额外字段；只有本组具有编辑操作且父级明细也允许时，子列才可编辑。
- 自定义范围支持主字段的相等、不等、包含、非空及数字比较。成员、主部门作为动态来源时由当前登录身份解析；没有主部门时不产生部门匹配。组织和静态选项常量在配置界面按名称选择。
- 普通记录修改使记录离开当前组范围时，数据和审计仍一起保存。响应仅返回无字段内容的保存回执，列表移除该记录。重复提交继续重新授权，不返回旧权限下的内容。

## 服务端边界

迁移 017 保存当前组配置和不可修改的配置审计。保存使用配置修订号，组织共享锁和数据对象锁保证与组织、数据写入及发布串行；审计失败时配置一起回滚。组选择只作为请求偏好，每次请求都重新计算成员资格、记录范围和字段权限。伪造组、跨工作空间、未知配置及非法筛选均被拒绝；仅添加已按后续验收开放。

列表和关联候选在 SQL 中先筛范围再分页，避免无权记录占满前 100 条或候选分页；详情、普通修改、归档和输出接口使用同一组规则。导出、打印本轮完成的是分别遮蔽字段的数据接口，尚无新服务端的实际文件下载及打印界面。原本地导出和打印入口保持原状。

数据发布检查纳入权限组修订和引用，禁止直接移除正在用于自定义范围的字段。停用组保留历史字段规则，但移除范围字段后必须调整条件才能重新启用，避免缺失字段意外扩大范围。历史记录继续按自身发布版本读取。

## 浏览器验收

使用独立合成应用“权限组办理验收”和“分组办理页”，没有修改原应用的身份对应或授权。管理员从界面创建并保存“登记组”“复核组”，重新打开核对。两个组都授予同一本地录入成员，验证组选择本身的隔离。

1. 登录成员后，多个组没有预选，尚不读取表单和记录。选择登记组后，仅显示“待登记”的一条记录。
2. 登记组可修改办理状态和登记数量；项目及复核数量只读，内部备注隐藏。把登记数量由 3 改为 5 保存，再从应用页面打开，值仍为 5。
3. 在应用页面把状态改为“待复核”。保存后显示“已保存；记录已不属于当前权限组范围”，登记组列表为空。
4. 切换复核组后可见两条验收记录。刚交接记录的状态为待复核、登记数量为 5，二者只读；复核数量可以由 0 改为 5，保存重开仍保留。
5. 配置和记录详情在 390×844 下的对话框宽度与内容滚动宽度均为 356，没有对话框横向溢出；明细表在自身容器滚动。已恢复默认视口和管理员账号。
