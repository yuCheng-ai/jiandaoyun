# CSV 范围、成员权限与文件交付验收

2026-10-09。管理员导出完整筛选结果或跨页所选记录；成员导出当前搜索结果中具有导出权限的记录和字段。已通过实际下载文件核验，未以按钮提示作为下载完成证据。

## 修改

- 管理员和成员共用 domain/csv.ts 与 services/downloadCsv.ts。UTF-8 BOM、引号转义和 CRLF 行分隔统一，单元格中的中文、逗号、引号、换行保留。
- 以空白或控制字符开头的公式样文本也添加文本前缀，避免此前只检查第一个字符时漏掉空格、制表符前缀。管理员与成员入口规则相同。
- 下载发起异常在原页面显示可重试反馈，保留筛选和选择。成功发起只提示“已请求导出”，不声称浏览器已完成保存。
- 保留原列表导出语义：当前配置的列和顺序、全部筛选结果、跨页所选交集；历史值按记录发布版本解释。成员在点击时重新计算记录范围、导出操作和字段授权，不从仅授予查看的其他组扩大导出权限。

## 保留边界

当前 CSV 遵循列表展示列；子表列仍为明细数量摘要，不宣称已经提供完整明细展开导出。成员授权是原本地前端逻辑，不能替代服务端导出接口。受限成员 PDF 实际文件、更多历史版本组合及最终 F1–F10 综合回归仍需继续检查；工作空间恢复文件导入与本轮已验证的表单配置文件导入是不同路径。
