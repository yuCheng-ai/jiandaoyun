# 仅添加权限与提交确认验收

2026-10-09。原生权限组现在可以只允许添加：成员填写、保存和续填自己的草稿，提交后由拥有正式记录访问权限的成员处理。本轮补齐迁移依赖，没有迁移原应用或激活旧权限转换结果。

## 执行规则

权限组的添加和已有记录操作分别计算。新增和草稿使用允许添加的组字段，再受页面可见、可编辑及所属明细限制；已有记录使用允许查看且匹配记录范围的组。允许显式合并时，每组先限制自己的操作和父子列，再合并，不能借其他组的字段或父级权限。

本人草稿不受正式记录筛选条件限制，但每次读取、修改和提交都重新检查当前组织资格与添加权限。其他成员看不到草稿；管理员保留管理权限。草稿仍不进入关联或流程。提交按原数据及明确页面版本检查，待保存修改、明细动作、状态转换和审计一起提交，保留记录与明细身份。

只添加的组不能读取正式记录列表、详情、页面记录、导出或打印，不能通过直接请求修改正式记录。两个业务入口都先读取实际权限，再确定可用记录范围；只添加时进入自己的草稿，不发起无权的正式列表请求。切到没有添加权限的查看组时，移除草稿选择并进入正式范围。原直接授权模式的本人只读草稿行为保留。

配置界面允许取消查看；取消时移除依赖查看的编辑、归档和输出操作，保留添加。勾选这些已有记录操作时同时勾选查看。只添加不展示无关的正式记录筛选，原筛选配置保留但不参与执行和模型移除阻断；恢复查看前，服务端再次检查筛选字段，拒绝启用已失效条件。

## 保存与重试

新增、草稿提交和普通修改共用保存后响应处理。先执行当前成员的命令或找回该命令已提交的资源，再按当前权限读取结果。当前无权读取时返回没有字段、值或修改版本内容的保存确认，避免将合法交接误报为失败。相同命令重试不重复写入或返回旧权限缓存；任务修改继续执行任务授权，不使用普通页面的无内容回执绕过授权。

记录写入的提交标识绑定所选数据权限组及页面版本。前端还绑定当前操作、记录和任务上下文；输入不变的同一次失败可原样重试，切换组会生成新的标识。服务端拒绝同一个标识用于其他组或不同内容。撤权后新的操作失败；已经成功的同一命令仅确认原结果，不恢复字段访问。
