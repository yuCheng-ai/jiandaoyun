# AI 快捷填报前端验收

日期：2026-10-08。参考 [官方快捷填报说明](https://hc.jiandaoyun.com/doc/23205) 的字段、示例、说明和预览配置。当前实现采用明确标记的本地规则演示，无模型、OCR、外部上传或网络请求。

## 已实现

- 扩展功能的独立设置入口：启停、文字/附图、最多 30 个目标字段、别名和说明、示例、搜索、失效字段移除、预览与取消保护。组织/关联/动态候选字段合计最多 5 个，图片/附件接收字段最多 1 个。
- 配置按稳定字段 ID 保存并进入发布快照，复制表单默认关闭。草稿修改不会影响已发布版本；引用字段删除和发起节点权限变化会在发布校验中阻止失效配置。
- 发布填写和成员新增记录入口共享“输入 → 检查 → 确认”弹窗。文字按标签行或 JSON 匹配，歧义、重复标签、格式不兼容和范围失效显示具体原因；不自动猜选同名成员或客户。
- 检查结果复用表单字段控件、组织选择器和关联弹窗，保留当前成员的数据范围。已填写字段默认不勾选；回填前展示关联带入、依赖清空和计算字段变化，覆盖或联动必须确认。
- 每次确认重新检查配置、表单值和候选数据。回填仅更新当前表单；提交、草稿和缓存仍由既有 FormRuntime 管理，解析过程不保存记录或执行扩展事件。
- 图片支持 PNG/JPEG/WebP/GIF，每张最多 5 MB，一次最多 5 张并遵守字段单多选限制。仅保留文件元数据和不超过 300 KB 的本地图片预览；不声称已识别图片内容。关闭弹窗后取消异步结果，读取图片时禁止提前解析。

## 自动检查

`tests/quick-fill.test.ts` 的 15 项测试覆盖标签/别名/JSON、歧义与取消、禁止网络、部门依赖顺序、失效/同名成员、数字与日期、图片限制及安全预览、未提交差异、部分必填与唯一值、隐藏/只读/条件容器、关联映射和成员范围、依赖清空、配置迁移、发起权限、版本/复制/存储失败回滚及失效配置发布阻断。

最终结果：`npm test` 212 项通过；`npm run build` 通过类型检查及打包；`npm run test:sites` 4 项通过，保留 Sites 所需三个输出文件。

## 边界与后续

当前只解析明确标签或 JSON，不支持任意自然语言、OCR、语音、PDF/Word 内容提取。字段说明供检查并保留到配置，不能当作已经执行的模型提示。明细子表不作为提取目标，现有记录编辑暂不提供快捷填报入口。表单保存/提交的完整校验依然必需。

本轮刷新时，旧支付验收表在当前工作空间中已不存在，故重新建立独立验收表。Repository 的整快照写入缺少跨标签页版本保护，列为下一步优先修复；尚未复现旧表缺失的具体原因。其他模块的历史截图不证明当前本地数据仍然存在。
