# 成员发布与访问设置验收

日期：2026-10-08。入口：表单发布 → 访问与填写设置 / 对成员发布 → 体验成员视图。

## 本轮实现

- 权限组模板、成员/部门/角色选择、有效在职成员预览、启停、复制、排序、归档恢复；成员可选择单个组或合并查看。
- 添加、查看、编辑、删除、导出、打印权限；全部、本人、同部门或条件筛选范围。操作及字段授权始终来自对当前记录生效的组。
- 以稳定字段 ID 配置不可见、只读、可编辑；未配置的新字段默认隐藏，父容器约束子字段。新增填写遵循表单设计及流程发起节点权限，已有记录按提交版本与当前权限组处理。
- 成员入口支持身份体验、搜索、分页、新增、编辑、软删除、详情、导出请求和打印预览。编辑复用字段控件和校验，保留隐藏值与只读值，拒绝越权联动及旧快照覆盖；保存沿用记录历史、事件与存储回滚。
- 填写链接开关、暂停收集、起止时间、数量上限、重复提交规则。访问配置立即保存到工作空间，与不可变的表单发布版本独立。

## 浏览器验收

使用本地“合同提醒 · 验收示例”，V3，三个字段：合同名称、到期日、负责人。没有修改生产简道云账户。

| 场景 | 操作与结果 |
| --- | --- |
| 部门授权 | 新建“添加并管理本人数据”，选择产品部，有效成员为张三、李四、许清。负责人设为不可见，开启导出/打印。保存刷新后配置保持。 |
| 本人数据 | 张三初次进入显示 0 条；旧数据无提交人信息，没有被误算为本人数据。张三新增记录、指定王五为负责人后，列表只显示本人一条。 |
| 字段保护 | 编辑张三记录时负责人隐藏，修改合同名可保存。随后增加查看全部组，记录中的负责人仍为王五，隐藏值没有丢失。 |
| 退出保护 | 修改后关闭出现“修改尚未保存”；继续编辑后内容保留并可保存。发布设置修改后导航同样有继续/放弃/保存并离开。 |
| 不同身份 | 李四看不到张三记录，提交自己的记录后只见本人一条。王五没有权限组，显示无访问权限。 |
| 权限合并 | 给张三追加“查看全部数据”。合并视图显示 5 条，但只有张三一条有编辑/删除/打印；李四和旧记录仅可查看。单组选回本人组后只剩一条且负责人列隐藏。 |
| 打印字段 | 合并列表中负责人可见，但打印只来自本人组，打印预览只含合同名和到期日，负责人未出现。 |
| 暂停/恢复 | 在 390px 发布设置取消“允许收集新数据”，保存并离开后新增按钮禁用，显示“表单已暂停收集”。恢复后新增入口可用。 |
| 关闭访问 | 关闭成员访问并保存后入口立即显示无权限；关闭填写链接后正式填写页显示“本地填写链接已关闭”。验收后均已恢复启用。 |
| 窄屏 | 同源框架 390×844，成员页和发布设置的 html clientWidth/scrollWidth 都为 390。权限编辑弹窗、成员编辑可用，保存名称“张三 · 权限与窄屏验收”，只读负责人保留。表格自身可横向滚动。 |
| 控制台 | 主验收页最近 error/warn 日志为空。 |

## 边界与未验证

这是当前浏览器的前端权限体验，身份选择不是登录认证。本地完整数据仍在工作空间内；渲染、关系候选和操作按权限约束，不能替代后端鉴权。管理入口保留完整管理能力。

旧记录没有提交人信息时不猜测归属。同部门规则使用记录提交时的部门快照与访问者当前部门匹配。收集数量排除草稿和回收站；回收后不再占用数量与重复提交资格。跨标签页并发同步、真实匿名访客识别、服务端锁不在此实现中。

成员 CSV 导出已按操作权限筛选记录/字段，按钮执行后浏览器工具未收到下载完成事件，文件落盘尚未确认。系统打印/PDF 落盘未验证，本轮只确认打印预览内容。窄屏 iframe 的返回图标两次出现工具定位失败，使用验收辅助页导航继续；桌面返回图标正常。
