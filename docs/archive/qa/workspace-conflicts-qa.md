# 保存冲突与恢复验收（2026-10-08）

## 本轮实现

- 保存前比较加载时的原始快照；其他页面保存、清除或损坏数据后，旧页面不能覆盖。
- 最近访问改用独立缓存，保持刷新后的最近使用列表，不写业务快照。
- 全局及弹窗内都有“保留与恢复”入口，保留旧页面输入。
- 失败操作在回滚前捕获独立副本；下载中清楚区分草稿、失败尝试和已保存数据。
- 设计可追加为新的未发布表单，关闭自动扩展、剥离发布历史，原表单及业务记录不做覆盖或重放。
