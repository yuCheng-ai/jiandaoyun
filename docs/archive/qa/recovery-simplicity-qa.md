# 保存提示与恢复交互简化

2026-10-09。范围：原本地表单设计器的多页面保存冲突、推荐字段弹窗及恢复入口。

后续已用按操作对象检查的公共保存机制替换本页记载的“仅新增独立表单”例外，公共弹窗的存储告警接口也已删除。当前结论与范围见 [通用交互巡检](project-interaction-audit.md)。下文保留上一阶段的交互证据，不代表当前自动更新边界。

## 问题与处理

用户要继续编辑表单。原来的公共弹窗默认注入全局存储警告，使推荐字段、选择器等无关操作也承受同一错误提示；恢复面板同时展示暂存、工作副本、原始数据和 JSON，主任务被工具说明淹没。原有不覆盖其他页面、保留输入的机制应保留。

- 公共弹窗默认不插入全局存储提示。页面仍保留保存失败入口，真实写入冲突继续阻止覆盖；需要时组件可明确启用提示。
- 默认恢复面板改为 560px，显示被更新的表单或业务内容名称。提供返回编辑、查看最新内容；有未保存设计时提供另存当前设计和成功后的继续编辑入口。
- 查看最新内容指向当前业务页面；目标表单已归档或不存在时回到工作台。链接在新页面打开，旧页面和输入保留。
- 下载、导入及 JSON 工具保留在折叠的“更多处理方式”中，默认不挂载。移除工作空间记录数比较和默认的零份暂存区。
- 原先因另一页新增独立表单而停止保存的情况可以自动同步。同步只读最新快照，保留已存在表单/记录的对象身份和设计草稿，写入前在共享锁内再次检查，业务校验在同步之后执行。

## 自动同步边界

这不是通用合并器。只允许新增应用/表单及归属于新表单的记录、视图、权限配置、扩展日志；现有应用、表单、记录、组织、支付、密钥和规则必须保持原样。本页已修改业务快照时也不能自动替换。首次保存示例数据中缺省的空数组与读取补齐的空数组按同义处理。

读取不得截断或清洗掉原始内容；兼容解析有数据损失、快照在检查后又变化、现有资源被修改、存储损坏或被清除时继续阻止旧快照覆盖。失败操作不自动重放。另存设计保留为未发布的新表单，自动扩展关闭，原业务记录不复制或覆盖。

现有记录/权限/组织和现有不同表单的修改仍可能触发保守冲突。逐字段比较、合并及完整服务端迁移尚未完成；不能将本次改动描述为任意多页面编辑自动合并。

## 验证

- 新增自动同步测试 7 项：含未保存字段与对象身份、无 storage 事件时锁内检查、新表单关联记录、首次示例保存、同表冲突、不丢本页未提交业务变更、已有资源变更、解析损失和检查期间再次更新。
- 新增组件测试 5 项：普通弹窗默认无全局警告、命名更新与当前页面链接、明确另存及保留原页、次级工具展开后才出现、已打开的旧页面缺少新增状态时仍能打开处理入口。
- 原冲突、恢复、写锁用例继续覆盖回滚、失败快照、不可覆盖损坏数据、另存未发布设计。
- 全量前端测试通过 471 项；完整构建、Sites 4 项和四个受保护文件摘要检查通过。未修改后端实现，本次未重复执行后端集成测试。
- 浏览器在独立的 `localhost:5198` 测试来源执行，未写入用户的 `127.0.0.1:5198` 业务数据或数据库：第二页新增表单，第一页未保存字段仍在并可保存；同表改名后旧页保存被阻止，未保存标签仍在；推荐字段无内嵌警告；Escape 返回编辑；另存后打开实际新表单，未保存字段可见；390px 窄屏正常。
- 内置浏览器的目标为空白新页链接没有立即出现在首次标签页清单中，随后通过可见链接地址打开新表单核验内容；不能用瞬时标签页清单断言业务另存失败。
