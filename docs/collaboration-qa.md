# 数据协作验收（2026-10-08）

## 功能划分

核对源站扩展页及[官方数据协作说明](https://hc.jiandaoyun.com/doc/15147)，此模块包含数据标题和表格快捷编辑。成员、操作、数据范围及字段权限归属[对成员发布](https://hc.jiandaoyun.com/doc/9089)。原计划的权限要求移至成员发布继续实现，不计入本次完成范围。

## 实现

- 数据标题支持默认取第一个有内容的可见字段，或按顺序拼接固定文字与字段值；最多 20 个片段，标题最多 200 字。人员和选项显示名称，数值 0 保留；隐藏字段不显示，空标题回退到表单名称与记录编号。
- 配置复用稳定字段 ID，支持排序、删除、示例值预览和实际记录副本测试。保存进入草稿，发布后新记录使用新配置，历史记录按自身版本显示标题。字段删除影响检查与发布校验覆盖标题引用。
- 列表、详情、工作台共用标题计算，列表可按固定标题文字搜索，CSV 内容增加数据标题列。
- 启用快捷编辑后，列表可直接修改文字、数字、日期、选择、人员、部门、地址和单条正向关联。沿用共享字段控件、动态范围、联动清理、计算、必填及唯一性校验；子表明细、附件、计算字段和反向关联不直接编辑。
- 保存前展示本次所有值变更，包括联动字段。保存追加修改历史并触发本地数据更新事件，保留记录的流程节点和版本；写入失败回滚记录、历史及日志。当前编辑快照过期时拒绝覆盖。
- 同一时间编辑一个单元格，筛选、分页和其他记录动作暂停；取消与路由离开有未保存保护。Ctrl/⌘+Enter 保存，Esc 取消；单行文字输入 Enter 保存。关闭确认后恢复输入焦点。

## 浏览器完整路径

在本地「合同提醒 · 验收示例」验证：

1. 配置「合同 · 」+「合同名称」，调整顺序后预览即时变化，恢复正确顺序并启用快捷编辑，保存发布 V3。
2. 提交「办公采购 · 协作验收」。V3 列表显示组合标题和三个快捷编辑入口，旧 V1/V2 记录保持原标题与无快捷编辑入口。
3. 单元格修改名称，Enter 保存，标题立即更新；负责人打开通用选择器并保存张三。详情显示组合标题及两条「表格快捷编辑 · 修改记录」。
4. 搜索「合同 ·」只显示 V3 记录。修改后尝试去发布页，选择继续编辑保留草稿，选择放弃修改后正常导航且原记录不变。去工作台的离开保护同样通过。
5. 刷新保留设置与记录值；工作台「我发起的」显示同一组合标题。
6. 390×844 同源框架中配置正确回显，页面 `clientWidth=scrollWidth=390`。数据表横向滚动局限在表格容器；编辑框自动滚入视野，实测左右约 109–385px，内容无内部横向溢出。验证取消确认、放弃不写入，以及实际保存「办公采购 · 窄屏复核」，主页面刷新后读到同一值。

验收发现并修复：单元格原有 200px 裁切限制遮挡编辑框；输入聚焦未把完整编辑框滚入视野；取消路由跳转后标签页标题仍改变。修复后复验通过。

主页面最终无 error/warn。窄屏框架切换期间记录过一次没有源码定位的 MutationObserver 错误；刷新后重复编辑、保存/放弃未新增错误，项目源代码及框架页没有 MutationObserver 调用。该单次诊断尚未定位，不将其写成已修复的问题。

## 边界与后续

当前快捷编辑是本地管理操作，字段规则依据记录所属版本；不是多用户安全权限边界。跨标签页/跨设备并发控制仍需持久化接口支持，本次快照检查只保护当前内存状态变化。成员权限组、访问及填写设置仍待实现。CSV 下载落盘、系统刷新离开提示的全部宿主行为、所有字段组合不在本次浏览器验证范围，模型校验另有测试。

下一步计划：成员发布与协作权限。未完成项：成员权限、智能助手、支付/AI 填报前端及系统打印输出等，见 [实施计划](implementation-plan.md)。
