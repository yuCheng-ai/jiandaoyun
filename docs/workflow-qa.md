## 比较与修复历史

1. 首轮 P2：顶部出现 26px 偏移。排查发现隐藏的文件输入框继承了表单控件的最小高度，导致 body 产生额外滚动空间。修复隐藏输入的定位及最小高度，并限制外层滚动。后续 DOM 验证 header.top=0、body.scrollTop=0；最终全屏证据中顶部完整。
2. 首轮 P2：连线停在悬浮连接点，与节点边框之间留白。将连接端口移回节点边界，仅把加号图标向外平移。最终节点局部对照和手动重连验证通过。
3. 交互 P2：Vue Flow 把空连线标签补成空字符串，造成多余历史记录。序列化统一空标签，并增加回归测试。浏览器验证新增后节点数 4，撤销为 3，重做为 4。
4. 窄屏 P2：完整节点文字工具栏过宽。改为图标工具栏，保留名称提示和可访问标签；390px 证据中保存、测试、启用均完整显示。
5. 后续对照：点阵密度调整至更接近来源。最终重新截取、打开全屏及两处局部并列图，未发现需要继续修复的 P0 / P1 / P2 差异。
