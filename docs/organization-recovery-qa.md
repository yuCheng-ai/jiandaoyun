# 组织编辑恢复验收

2026-10-09。原本地组织管理的部门、成员、角色、角色分组和批量成员修改已接入统一编辑恢复。刷新后由用户明确恢复；只有保存成功才变更正式组织配置并清理暂存。服务端组织与企业账号迁移仍按 development-plan.md 单独推进。

## 编辑和保存行为

- 保留未填写完的工号、名称、部门、角色成员和授权条件，不将空输入偷偷补成默认值。新增对象在恢复和重试时保持同一身份。
- 保存中阻止重复提交和关闭；校验或持久化失败保留输入，并在弹框内显示具体原因。关闭和离开路由需要明确放弃修改。
- 恢复核对当前成员、组织与应用/表单目录；组织或授权对象变化后拒绝直接恢复或覆盖。保存取得写锁后再次核对原始组织上下文，不自动合并陈旧权限。
- 批量编辑暂存绑定操作类型及成员集合。刷新后需要重新选择同一批成员并打开同一操作，不自动恢复全局勾选状态。
