# 原权限组转换与迁移检查验收

2026-10-09 06:08，原表单访问权限已接入历史资源准备：保存独立权限组配置，保留操作、记录范围、字段规则、收集设置和启停状态，并在界面逐组检查。配置转换不启用服务端授权；权限执行适配与整套应用导入仍未完成。

## 保留的权限含义

| 原规则 | 转换结果与边界 |
| --- | --- |
| 选择单个权限组或允许合并 | 保留原组身份和 allowMerged，不展开成一份永久合并授权 |
| 查看、添加、编辑、删除、导出、打印 | 分组保留全部操作；字段权限随原组保存，后续执行必须从具有对应操作且满足记录范围的同一组取权限 |
| 仅添加 | 保留 create 单独存在，不自动补查看；新建字段范围仍由发布页面与原流程开始节点约束 |
| 本人创建、记录创建部门、自定义范围 | 保留原范围；记录创建部门直接匹配当前成员部门，不扩大为子部门记录 |
| 部门作为权限对象 | 保留动态部门引用及包含下级的成员资格规则，与记录范围中的部门规则分开 |
| 主字段和明细列 | 保留原字段 ID 以及隐藏、只读、可编辑配置；父子限制不能在后续合并时绕过 |
| 草稿或历史版本独有字段 | 在全部保留版本中解析，不能仅以当前草稿判为失效 |
| 停用或归档权限组 | 保留组及其配置并检查，不能丢弃后宣称迁移通过 |
| 收集开关、时间、数量、重复填写 | 保留原值和时间文本，不舍入数量、不自动开启；无时区时间的执行依据仍需明确 |
| 历史权限对象 | 保存独立来源引用，不生成账号、授予权限或派发待办 |

迁移只接受已识别的规则。重复组身份、未知操作、非法范围、失效字段、无条件自定义范围和未知配置均阻止整份访问权限输出；已通过的其他组可以供界面检查，但不能作为部分授权生效。旧快照保持不可变，新版检查通过明确保存产生。

筛选中的组织身份常量按成员或部门类别对应到目标身份。只有出现在历史权限筛选里的身份也会进入本地身份清单。普通文本常量保留原值；当前成员与当前部门来源保留为运行期来源，当前部门仍须按原主部门语义执行。文本字段冒充组织身份、历史版本身份类别冲突、组织标识的文本片段或数值筛选需要人工核对，不能替换字符串后改变匹配含义。条件是逐项同时满足，不能删掉失败条件扩大记录范围。

原始包、转换结果和摘要在同一资源准备事务中写入。页面只读取摘要，转换后的完整条件保存在服务端投影。一个组失败时，该表单不输出可供导入的 access 配置。入口维持 importAvailable=false，服务端没有新增权限启用接口。
