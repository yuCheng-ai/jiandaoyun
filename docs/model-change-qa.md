# 数据字段变更与草稿恢复验收

2026-10-09 00:12，数据管理已接通字段变更预览、显式发布和已保存草稿放弃。主字段与明细列共用同一检查：列出新增、移出新版本、更名、必填、长度、数值范围和小数位差异，检查服务端页面、关系、流程及权限使用情况。该能力覆盖当前服务端支持的文本、数字和单层明细，不包含旧本地公式、动态来源及扩展配置。

## 已验证行为

- 数据对象草稿允许保留尚未解决的字段引用；正式版本保持不变。发布时，仍被当前已发布页面或关系引用的字段不能移除。默认兼容页面仅在旧定义接口会同步发布时例外，预览明确说明该行为。
- 流程绑定数据和页面版本，历史记录和任务不随模型发布自动迁移。预览显示记录各版本的使用中、已归档数量，以及未完成和已完成任务数量。只对本次新增及修改规则的字段检查现值和新增字段默认值，返回不符合规则的记录数，不返回记录身份或业务内容。
- 模型检查与记录写入通过数据对象锁串行，批量检查不会把并发新增误计为同一批次的记录。预览标识包含模型、引用配置版本、授权和使用情况；字段或使用情况变化后，旧预览提交返回 409，草稿保留。
- 移除字段和修改已有数据约束必须提交匹配的预览标识。新增及更名的旧 API 调用仍可使用兼容路径，但发布始终执行服务端依赖校验。新数据管理及原协作发布界面均先检查再确认。
- 数据草稿显示与已发布版本是否一致。放弃已保存草稿恢复最近发布的名称和模型、增加修改版本，并保留其他页面草稿和业务记录。未发布过的对象没有可恢复的发布版本。陈旧修改版本、无权和其他工作空间的请求被拒绝。
- 发布和草稿放弃与不可变配置审计同事务提交。故意使审计写入失败时，模型、发布版本及修改计数全部回滚。重启后发布历史和草稿恢复结果保留。
