## 字段与数据规则

| 范围 | 当前行为 |
| --- | --- |
| 日期 | 支持年-月-日与精确到分钟的本地日期时间；校验真实日历、闰年和时间范围，按输入原样保存 |
| 单选 | 单选按钮与下拉框绑定单选数据，保存稳定选项 ID，显示选项名称 |
| 多选 | 复选框与下拉复选框绑定多选数据，保存不重复的选项 ID 数组；下拉复选框可展开选择并显示已选名称 |
| 联系方式 | 手机号与邮箱格式由服务端校验；邮箱属于文本的数据规则 |
| 页面规则 | 新字段可就地配置选项、默认值、日期格式及文本/数字规则；已有字段的共享规则只读，本页名称、布局与提交必填独立设置 |
| 数据管理 | 采用文本、数字、日期时间、单选、多选、手机号、明细等数据类型名称；不将某种页面控件名称当作数据类型 |
| 关系 | 候选搜索、列表与映射预览显示选项名称；写入仍使用 ID。回填要求类型、日期格式和选项身份兼容，多选包含判断按完整选项匹配 |
| 等待 | 多选等待条件按集合比较，不因勾选顺序不同而失效；发起前拒绝不存在的选项 |

修改选项名称保留身份。调整共享规则先检查页面和记录影响；发布新模型不会改写历史页面或记录版本。当前只支持自定义静态选项，动态来源和不支持的格式会明确拒绝。
