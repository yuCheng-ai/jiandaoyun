# 本地应用迁移检查验收

2026-10-09 03:34，北京时间。协作入口新增按应用检查迁移资源的功能，读取最新已保存内容，按表单与发布版本列出待接入能力、需核对引用和待映射权限。本次交付是只读盘点，不执行上传、导入、身份授权或入口切换。

## 检查范围

- 包含应用中的归档表单、当前保存草稿、历史发布与当前发布、草稿及已删除记录、明细行和处理轨迹数量。记录按其引用的发布版本检查，不用当前草稿解释旧值。
- 遍历完整字段 registry，区分数据字段与展示控件；基础类型支持与具体规则分别判断。动态来源、公式、唯一性、掩码、条件显隐、超限明细、未知格式等标为待接入。
- 按来源版本列出动态选项、关联字段、子流程、助手动作和打开表单按钮的依赖。助手保留目标发布版本及动作位置；跨应用依赖列出目标应用，同名表单不合并。
- 识别记录创建者、历史成员/部门字段及明细值、选人配置、流程负责人、权限组、提醒和角色授权涉及的身份。只形成原身份清单，不按姓名生成服务端对应关系或赋权。
- 保存未启用的流程与扩展仍计入盘点。权限、数据视图、支付订单和扩展运行记录保留在范围内；签名凭证只核对引用，报告不复制密钥或业务值。
- 相同版本存在不同内容时同时检查冲突内容，明确阻断解释歧义；发布版本缺失、重复记录身份、未定义字段/列、失效节点引用等会指出所在表单与版本。

迁移源从持久化 Repository 只读获取，独立于当前标签页的旧内存副本。兼容读取如果会过滤业务记录、删去未知配置数组或截断资源列表，检查明确停止。最近访问列表属于导航缓存，不阻断业务盘点。源内容变化后旧结果标为过期，重新检查才更新；原工作空间、编辑草稿和写入基线均不改变。
