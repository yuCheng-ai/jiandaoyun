# 数据推送与流程插件验收

日期：2026-10-08。结果：本轮前端范围通过。技术栈保持 Vue 3 + TypeScript + Pinia；扩展页独立懒加载，配置、校验、执行结果和存储分层。

## 验收路径

| 项目 | 实际操作与结果 |
| --- | --- |
| 配置校验 | 空推送名称不能进入下一步；完整 HTTP 地址、签名引用和发送字段分别校验，错误可定位到对应步骤。 |
| 数据推送 | 创建“订单变化同步 · 交互示例”，选择新增/修改事件、example.com 演示地址、两项字段；右侧 JSON 随事件与字段变化。保存、刷新后配置保留。 |
| 失败与重试 | 模拟超时显示失败步骤；定位到测试场景，切换成功场景后重试成功并清除旧错误。未选中的删除事件返回“未触发”，样例只含记录标识。 |
| 插件绑定 | 选择计算金额，数量读取数字字段，单价固定 2.5，结果映射到数字字段。兼容字段选择器只展示数字目标。 |
| 插件试运行 | 示例输入 100 × 2.5 得到 250；失败场景无回填，重新试运行成功。保存后从扩展页定位到流程画布的对应节点。 |
| 发布与执行 | 示例表单配置发起人审批并发布 V1；提交数字 3，审批后变为 7.5。重新加载最新代码后提交 4，详情不必重开即变为 10，流程结束。 |
| 事件日志 | 正式提交产生新增日志，审批后的修改日志包含回填后的 10。日志标明表单事件/试运行、本地运算/模拟连接。 |
| 历史重试 | 失败筛选仅显示失败记录；从日志使用旧样本重试，重新得到 250，不改变正式记录。 |
| 字段影响 | 删除数字字段前列出推送发送内容和插件输入/回填两项影响；选择保留，配置和字段不变。 |
| 取消保护 | 更改推送名称后取消，出现继续编辑/放弃修改；放弃后仍显示原保存名称。 |
| 窄屏 | 390×844 推送编辑器步骤、选择项、测试和固定页脚可操作；弹窗 clientWidth 与 scrollWidth 均为 356，没有横向溢出。 |

## 实现边界

- 金额计算、组合文本和记录回填在本地执行。连接测试实际在本地生成并核验签名；演示密钥仅保存在本地浏览器。HTTP 和通知仍为模拟，不发送网络请求或消息。
- 自动推送源包含正式提交、本地审批/重试、管理编辑、移入回收站与恢复。四类事件均有实际本地来源；仍不向外部发送请求。
- 已提交记录使用其发布版本；修改草稿不修补历史配置。当前插件重试沿用原版本，日志重试只操作副本。组织成员按当前状态解析。
- 本轮补齐数据推送、流程插件、提交提示、打印模板和数据详情；在线支付、AI 填报等继续列在前端补齐计划中。
- 影响提示覆盖本表推送、插件、条件节点及显隐引用，不是所有跨表关系的全局依赖分析。
- 自动化测试覆盖模型和存储，浏览器覆盖上列路径；未对所有字段类型与插件输入组合做穷举。

下一步计划：继续补齐其余扩展模块的前端配置。未完成项：系统打印输出待验收，支付、自定义按钮、数据协作、智能助手等尚未实现；真实外部执行不在前端范围。


## Secret 配置与提交提示复验

- 点击事件复选框不再给整个分组绘制橙色轮廓；可操作控件保留键盘焦点样式。
- 旧占位凭证显示就地生成指引。生成、显隐、复制反馈、确认重新生成、保存刷新恢复均完成浏览器检查；复制 API 返回成功，系统剪贴板内容未另行读取。
- 无效地址禁用生成/重新生成与测试；同一个 Secret 验签得到模拟 200，接收端 Secret 不一致得到模拟 401。重新生成后清空上次测试结果。测试请求展示不含密钥。
